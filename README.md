# 👀 peekie - Your Thoughts, One Keystroke Away

## 🚀 What is peekie?

peekie is a tiny, invisible scratchpad that lives quietly on your Mac. Think of it as a Post-it note that appears the moment you need it and vanishes when you don't. Press a shortcut, jot down a quick thought, press the shortcut again, and it's gone. No windows cluttering your screen, no apps to manage, no accounts to create.

It's built for people who want to capture an idea before it disappears—a phone number, a sudden insight, a reminder for tomorrow—without opening a heavy notes app or waiting for a cloud sync.

### 4. Set Your Shortcut (First-Time Setup)
- When peekie opens, you'll see a small menu bar icon (it looks like a tiny eye).

- Press the shortcut anytime to see your note again.

## 🧩 Frequently Asked Questions

### ❓ Is peekie free?
Yes, it's completely free and open source.

### ❓ Do I need an account?
No account, no email, no sign-up. Ever.

### ❓ Does peekie require internet?
No. It runs completely offline. Your notes never leave your computer.

### ❓ Will peekie work on my Mac?
peekie is built for macOS. Make sure you're running macOS 12 (Monterey) or newer for the best experience.

### ❓ Where are my notes saved?
Your notes are stored locally in a small file in your home directory. They stay on your Mac and are not sent anywhere.

### ❓ Can I delete a note?
Yes. Simply clear the text in the scratchpad, close it, and it will save as an empty note.

### ❓ I can't see the menu bar icon?
If you have many icons in your menu bar, it might be hidden. Click the chevron (or the extra icons button) in the menu bar to see it. You can also press your shortcut directly without needing the icon.

### ❓ What if I forget my shortcut?
Open peekie from the menu bar icon and go to Settings to see or change your shortcut.

### ❓ Is it safe to download?
Yes. peekie is open source, meaning the code is publicly available for anyone to review. It has no network access, so it cannot send your data anywhere.

## 🔧 Troubleshooting

| Problem | What to Do |
|------|------|
| The app won't open | Go to System Settings → Privacy & Security → Scroll down → Click "Open Anyway" next to peekie. This happens because the app isn't downloaded from the App Store. |
| The shortcut doesn't work | Make sure you've set it in Settings. Also check that you're not already using that shortcut with another app. |
| The window is too transparent | Adjust the opacity in Settings. |
| I want to reset my note | Delete the text in the scratchpad and close it. It'll start fresh next time. |

## 🛠️ For the Curious: How peekie Is Built

peekie is written in Swift and SwiftUI, using Apple's AppKit framework. It's designed to be lightweight (under 5 MB) and to launch instantly. The translucent window is created using AppKit's NSVisualEffectView, giving it that beautiful native macOS look.

The project is open source, so developers can inspect the code, contribute features, or fork it for their own needs. If you're a developer, feel free to explore the repository, open issues, or submit pull requests.
